# Reel Script Template — 30-second default

The shape `reel-scriptwriter` produces. Saved at `client-data/_content/reels/<YYYY-MM-DD>-<slug>.md`.

```markdown
# Reel · {topic} · {duration}s

## Storyboard

| t (s) | What happens on screen | What is said / overlay text |
|---|---|---|
| 0–2 | {b-roll cue} | **HOOK:** "{≤ 8 words}" |
| 2–10 | {visual} | {insight sentence 1} |
| 10–18 | {visual} | {insight sentence 2 — optional} |
| 18–25 | {demo or proof} | {1-line evidence} |
| 25–28 | {tight on coach face / product} | **CTA:** "{≤ 8 words}" |
| 28–30 | {loop visual back to hook frame} | {repeat hook visual, no audio} |

## Voiceover (full text, no timestamps)
{75–90 words. Conversational. Spoken, not written. Use contractions.}

## On-screen text (overlays)
- 0–2s: "{hook text}"
- 25–28s: "{CTA text}"
- Optional emphasis word(s) at: {timestamps}

## Caption (FR)
{≤ 150 chars. Plain. No hashtag stuffing — 3 max, end of caption.}

## Visual / b-roll direction
- {bullet 1, see brand/visual.md §photo-direction}
- {bullet 2}
- {bullet 3}

## Audio
- Music: {genre / mood — e.g. "low ambient, no lyrics"} OR {trending sound name if relevant}
- VO mic placement: {close, warm}

## Why this works (internal note, not posted)
{≤ 40 words — the hook mechanism, the audience insight, the ask}
```

## Hook flavors (pick one per reel)

| Flavor | Pattern | Example |
|---|---|---|
| **Contrarian** | "Tout le monde dit X. C'est faux." | "Compter ses calories ne fonctionne pas pour la plupart." |
| **Specific stat** | "{number} {audience} {do/don't} {thing}" | "9 clients sur 10 ratent ça la première semaine." |
| **Callout** | "Si tu {behavior}, regarde ça." | "Si tu manges propre et tu ne perds pas, regarde ça." |
| **Self-deprecating** | "J'ai fait {dumb thing} pendant {time}." | "J'ai compté chaque calorie pendant 3 ans. Pour rien." |
| **Question** | "Pourquoi tu {behavior} quand {context}?" | "Pourquoi tu manges plus le dimanche soir?" |

## Length budgets

- Hook: 5–7 syllables in FR / EN, 3–5 words in AR
- Insight: max 2 sentences, ≤ 25 words total
- CTA: imperative verb + one noun

## Banned reel patterns

- "Today I'm gonna show you…"
- "You won't believe…"
- "POV: …" (overused)
- Counting fingers / pointing at text (unless ironic)
- Generic gym B-roll without coaching context
