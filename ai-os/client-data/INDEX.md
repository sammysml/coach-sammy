## How to use this file

- **Before any cross-client work** (monthly review, broadcast, content), scan this list.
- **When you receive a DM from a name you don't recognize**, grep here first.
- **When you delete or archive**, update both this file and the folder structure.

This file is committed to git (the only `client-data/*` file that is, alongside `SCHEMA.md`). The actual client folders are gitignored — only this list and the schema doc are shareable.
